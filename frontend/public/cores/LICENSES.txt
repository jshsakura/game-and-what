fbalpha2012_cps1_libretro.js/.wasm came from the npm package
@emulatorjs/core-fbalpha2012_cps1 (built by the EmulatorJS project from
https://github.com/libretro/fbalpha2012_cps1, itself a CPS1-only split of the
old FB Alpha 2012 codebase — much smaller than a full FBNeo/MAME build since
it links in only the CPS1 driver). That package ships the core 7z-compressed
and wrapped for EmulatorJS's OWN loader, not as a standalone Nostalgist-
compatible module, so the .js here has its export tail rewritten from
EmulatorJS's `EJS_Runtime`/CommonJS wrapper to the plain ESM
`var libretro_<name> = (() => { var _scriptDir = import.meta.url; ... }`
shape every other core in this folder already uses — the WASM binary itself
is untouched. Unlike every core above (extracted as-is from an upstream
prebuilt bundle) and potator/fuse below (compiled from source via emsdk +
RetroArch), this one required that manual wrapper rewrite; see
frontend/src/emulator.jsx for how it was verified to boot correctly.
